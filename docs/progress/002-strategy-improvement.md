## 4. 从源码与轨迹到假设

| 观察 | 可支持的研究假设 | 不能作的结论 |
|---|---|---|
| sk48四次首关失败；p0曾16步预测一致但未过关 | 目标假设与转移模型必须分开；需要可区分目标的证据 | 加BFS就能解；模拟器拟合高就代表规则完整 |
| lf52四次只过一关，轨迹把settled不变当无效、漏用动画 | 需要让有信息的暂态被实际解释，而不只提供API | 每回合塞满所有动画一定有益 |
| tn36从3.57到100波动，成功轨迹用动画及可反驳探测 | 有效信息使用方式值得泛化 | 单个成功轨迹证明方法稳定 |
| 基线关闭world-model摘要、保留推理与函数 | 在固定强底座上试稀疏证据检索 | 自动长摘要是确定优化 |
| 各fork共享大部分核心代码 | 先看真实diff和版本 | 合并三个高分fork等于模型集成 |
| 原调度在context裁剪时交出slot | 将收益与prefix成本一起研究 | 更频繁切换就更公平且更强 |

## 5. 最终研究取舍

**主线**：目标/机制假设可证伪，突破首个未解关、扩大加权关卡覆盖。用自建局部程序辅助规划，但避免把已写出的模拟器当真理。

**支撑线**：裁剪后可检索的原始证据、参数化函数复用、缓存成本感知的预算分配。基线已经具备的动画、函数保留和调度不能重复算作新贡献。

**暂缓**：从零RL、大模型训练、多角色辩论、强制每步重建/验证整个世界模型、单纯增强提示词或大量seed调参。前沿公开集满分往往使用不同资源或协议，不能当离线参赛预期。

强制摘要和更多guard缺乏清晰收益的公开负结果已继承。研究路线围绕理解与学习，不围绕门控。
