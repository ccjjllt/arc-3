# 010 — 按动作检索完整动画计划

日期：2026-10-13。对应[研究决策](../../research/010-research-decision.md)、[进展](../progress/010-retrievable-animation.md)。

## 假设与隔离范围

相同Flash-Next与原调度/墙钟下，模型能按真实旧动作取回中间帧，可能纠正仅看稳定末帧的机制误判，增加后续关卡覆盖。该假设尚未经过模型验证。现有稳定history已完整；新信息仅是旧动作动画链。

只提供只读、按需查询。短通用API说明是接口的一部分，不添加跨关策略、自动反思或游戏特定提示；003/006/007全部关闭。当前帧切片仍使用原接口；008可为内部坐标检查组件。不改模型、量化、serving、上下文窗口、调度、并发、动作批次、目标marker或reset策略。

## CPU阶段

- 使用公开SDK返回帧，保留session、attempt、action_num、level_before/after、frame_index和内容hash；RESET不能覆盖旧attempt的同号动作。
- 复现005中已公开的tn36五个点击序列；这是一段新的独立观察，不从日志运行任意代码，不读游戏实现或隐藏状态。
- 后续动作/RESET后重读原动作的全部帧与指定区域，校验哈希和坐标；记录尺寸、压缩/索引开销、查询时间和字符串长度。
- 单游戏短序列的读写速度不外推110游戏9h内存峰值；正式集成前必须另有存储上限和淘汰显式语义。
- CPU脚本/手工校验产物，不新建test或CI。无GPU启动。

## 接入门槛

在真正action返回处capture，在现有工具通道提供按action选择；不能仅实现未暴露给模型的工具。并发会话隔离，返回明确level/attempt，查询旧帧不改current_frame也不调用action。未找到引用要报告原因，绝不返回latest冒充旧帧。

轻量日志至少包括：捕获动作/帧数、可读取动作数、查询次数、查询非latest动作次数、返回字节、缺失/越界/错误次数、capture/query CPU时间。stdout与request日志抽查须连接到模型实际后续采用，而非只看工具调用数。记录prompt token成本与context trim，防止原始帧过多挤占推理。

沿用006已知12游戏池及顺序，避免看到结果后选局：


baseline → retrievable_animation，各1遍、3482秒、10活跃流；一次模型加载，独立CPU会话和缓存清理；warmup真实动作0。预计总会话约2.2h、平台上限9000秒、启动上限1200秒，参考历史不是精确耗时保证。实现配置已保存于[010-retrievable-animation.json](../../experiments/010-retrievable-animation.json)，实际启动状态与源码冻结记录以进展为准。

实现API为 `animation_refs(limit=16)` 列出精确引用，`animation_at(ref)` 按引用取回 `FrameView` 列表和单独的before帧，继续用现有ASCII/segmentation访问方式。每session最多128条动作metadata、4MiB帧JSON；进程总帧JSON最多64MiB、128个session。字节上限不是RSS上限；独立元数据记录数同样有界。超过容量明确淘汰或整记录拒绝，不截断动画冒充完整链。每个真实RESET增加attempt，动作序号使用真实GameRun记录。原latest动画接口保持原语义。

同池组间比较，不与005全25均分直接比较；与006历史同池只做背景定位，不是同时随机对照。固定baseline先运行仍有顺序/缓存/随机影响。若通过首筛，另开候选先运行的确认会话，不覆盖首轮产物。尾部调度开关保持remaining；调度经验表研究另开实验，不混入本轮。

## 结果判读与停止

优先看非latest查询→取得原先缺失的关系→推理/动作改变的采用与行为证据链；该链条本身不证明净提分因果。同时保留全12游戏的分数、关卡、全通、动作、生成/输入tokens和耗时。

读取错绑即停止；零采用则修接口，不原样扩大预算；有采用但没有多病例净覆盖收益不晋升；少量均分正差不足以证明有效。两轮证据一致才考虑全25筛查和下一次正式候选。没有工程交付或采用证据时，不为赶每日槽位提交。

## 备选

80k tail只替换现有调度公式的future-reward项，需有足够排队/交接压力才能验证；12游戏/10slot对它可能太弱。CPU静态排序敏感性不能给出反事实得分。若动画查询未被采用或收益集中在单一病例，则比较该备选与显式状态转移证据候选的机会成本，再决定下一编号实验。
