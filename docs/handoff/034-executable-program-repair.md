## 2. 对原思路的保留与修正

**保留“少加记忆、先修执行链”的主线，但作六项调整。**

1. **修当前程序，范围要小。** 033重新搭了一套错误的棋盘解析器；下一版优先修正在使用的输入构造或局部规则，继续使用已有目标/搜索函数。若现有算法本身被反例否定，再修对应规则，不能永远假定“只有像素错”。
2. **全动作经过统一入口，不等于全动作都有正确预测。** 无模型时允许探索；已有合同的计划出现 mismatch/unknown 时停止该批后缀。检查器也可能错，必须允许撤销合同、重新观察与受限探测。
3. **检查通常在CPU执行，修复按需调用模型。** 不加每步LLM审查，不把局部失配升级成全历史重放或整套世界模型重写。
4. **ft09只作机制诊断。** 它在032全池两臂均100分；真实提分靶点应转向su15及其他未完成游戏。检测出su15双追兵失配，也不等于已学会正确动力学。
5. **程序修复不能包办初始发现。** g50t、tn36在032候选0关，可能根本没有可修的有效程序。此类问题需要目标发现或有区分力的交互，安排独立的035支线，不能硬套修复器。
6. **48小时是产出候选和证据的工作目标。** 不是承诺正式涨分；自然入口、消费链或收益不成立就关闭该版，保留009。

记忆仍可在后续保存“规则＋证据＋程序版本＋适用条件”，并允许反例撤回。当前`solved_level_memory.py`首次规则写入后不自动修订，软重置也可能污染动作尾部；这些是后续改进点，尚非032隐藏退分的已证实原因。

**Heliosli v8确有接线增量，也有关键边界。** 静态代码显示`patch_rule_lab.py`把真实Python工具的`action_handler`包进`guarded_actions`，反例通过结构化反馈及中断异常返回。因此注册之后不需要模型每次手写`expect/read`。但首次注册仍依赖模型主动调用新工具；未注册时原样执行，可能重复021的“接口存在、有效覆盖为零”。

## 6. 034最小实现合同：打通当前程序到真实动作

两项CPU工作可并行准备，合成一个小候选；首轮不默认叠加032记忆、030变量持久化或额外reviewer。保留009的模型与服务。以下接口名称为建议，尚未实现。

**工作包A：局部程序修订和确定消费。**

- 输入仅含当前真实Python代码/保留函数、当前公共观测、已发生的相关转移、当前计划及具体矛盾。取有任务意义的局部像素或对象成员；不要要求模型重新抄写全4096像素。
- 返回一个自包含的可执行单元，例如`plan_program(frame, parameters)`，明确替换哪个旧输入构造或函数、依赖哪些现有规则、输出目标/差异/动作与可观察预测。坐标、对象语义和规则可以是假设，必须标注范围，不能冒充宿主真值。
- 宿主在零环境动作环境里暂存并运行候选。可由原始帧验证的像素声明直接核对；有真实历史转移就检查相容性。重用同一反例不算独立泛化验证；空搜索、空差异、`ok=True`或编译成功不算任务已解。
- 验收后**由宿主运行依赖新输入的目标和计划函数，再经既有动作入口执行首步**。记录输入观测ID、函数hash、目标结果、计划hash和实际动作。不得继续执行预先手写的旧目标/旧动作，也不能仅把修复代码发回上下文等待自愿使用。
- 未通过则恢复旧函数/历史；033已具备部分暂存与回滚，可直接复用。真实动作一旦已发生，不能把环境伪装回旧状态或自动重发。

**工作包B：统一动作入口和结构化反例。**

事件最少包含`game / level / attempt_event / observation_id / program_hash / before / action / expected / observed / status`。attempt由公开RESET、死亡等事件派生；无法确认的软重置保留unknown，不能假装知道引擎内部状态。观测序号跨调用递增，像素不变也产生新事件。

| 情况 | 执行行为 |
|---|---|
| 无注册合同 | 记录unverified，保留009探索能力；不声称已经验证动力学 |
| 合同有效，预测可比较 | 动作前冻结预测；只发一动作；随后用新观测核验，再决定下一步 |
| match | 只说明所选投影一致，允许继续当前短计划 |
| mismatch | 停止本批未执行后缀，把真实反例交回局部修复/目标修订/主动探测；不自动认定预测器或提取器哪一个错 |
| unknown、缺字段或检查异常 | 停止已受检计划的后缀，失效本次合同，返回主循环重新决定；不在同一代码块静默降级执行整批 |
| 换关、死亡、RESET、WIN | 先按生命周期边界处理，失效旧布局/目标/计划，避免误报成物理反例 |

动作标签只用于日志。检查的对象是本次动作声明的可观察变化，材料守恒、角色存活等必须有证据支持，不能硬编码为所有游戏真理。`r11l`已有“模型检查否定、实际动作成功”的反例，必须保留作为误拦截回归。

**必须解决第一条预测从哪里来。** 全动作hook覆盖100%，仍可能只有0个动作拥有有效预测。首版增加一次受限的“计划合同建立”分支：本游戏尚无合同、当前Python调用将连续执行动作、且有可引用的现用程序时，宿主主动用当前代码与公共观测发起一次限额请求，要求模型绑定现有程序及下一步预测；不是等待它自愿调用新API。

触发必须覆盖两种真实路径：显式多动作batch在首步前暂停；同一Python调用通过循环或多个helper连续发送单动作，则在**第二次动作发送前**暂停，使用第一步后的最新观测和当前snippet源码。不能只检查`len(action_batch)>1`而漏掉su15的连续单动作helper，也不要求静态猜出任意Python的未来控制流。暂停后停止旧代码后缀；第一步已经发生时明确记录，不回滚或重发。独立验收后，宿主从最新状态注册并执行重算计划的下一步。若没有有效产物，明确记录失败，释放到普通求解，并为该触发去重；不循环索取合同。

注册要区分“可执行、符合已见证据、经新转移支持”。动作前能独立检查观测提取、schema与历史相容性，不能验证尚未发生的动力学。无历史支持但有具体、非空、可观察预测的首步，先作为待验证合同执行一个受限真实动作，再按新证据更新；格式验收不能标成物理正确，也不能设定一个永远无法产生首条证据的启动门槛。

这条入口仍是假设，需要在线验证。若只能实现“修复分支产生的短计划受检”，就按这个范围报告，不能称已覆盖所有自然静默错误。没有有效程序的初始探索交给009或后续035。

## 8. 一个新发现的预算边界，需要明确处理

009的正式`31920 = 532×60`是游戏会话开始后计时的上限，**不是已经扣除安装、模型加载和网关等待的Notebook剩余时间**。冻结Notebook正式调用`soft_end=None`，构建器也明确保留此行为；框架只有收到非空soft_end才建立统一截止。可见代码没有自动扣除加载时间。[构建器](../../scripts/build_submission.py) · [009冻结Notebook](../../notebooks/009-baseline-submission/submission.ipynb)

因此新增候选要从Notebook最早可记录的时刻记总耗时，按9小时减实际已耗时与收尾预留，限制主请求、修复请求和动作发送；平台初始化可能早于首cell，仍需留余量。发生动作回调超时时不能自动重复已可能接受的动作。

保留009冻结原件；预算保护若改变求解行为，要作为明确的公共运行条件或单列改动记录，不能把差异全归为程序修复。研发7254秒/25题的缩放对照也不完全等价于110隐藏游戏的正式运行。**没有正式日志，不能断言009实际超时，更不能把这一点作为032退分根因。** 已修好的线程退出快照问题无需重开研究，这里只补新增开销的总时限边界。

## 9. 如果主线收益不足，下一项做什么

**035候选：只在有明确争议时进行区分性探测。** 适用于没有可靠程序，或两个规则都解释已有历史却给出不同后果的状态。让模型提出至多两个解释和各自预测，选择一个能区分它们的合法动作；真实执行一步后更新或撤回规则，再决定是否继续。初始最多1–3个探测动作，计入原动作和时间预算；限额不是已验证最优值。

这里不能在比赛环境克隆状态、回到未来、读取引擎答案或把RESET当免费撤销。候选模拟可以在CPU上运行，但真实动作只有一条轨迹。Heliosli v8的probe首步接线和OPINE的探索思想可借用，必须证明“探测 → 区分假设 → 改变计划”，不能只增加随机动作。

优先级与停线原则：

- **P0：034执行链。** 两天内争取一个有自主消费和自然覆盖证据的新候选。
- **P1：035区分性探测。** 若034只能覆盖已有好程序、首关发现仍弱，独立验证该方向，不直接把两个候选糊在一起。
- **P2：可撤回的规则记忆。** 基于已验证程序及适用范围复用；不是扩大上下文或永久pin首次规则。
- **P2：服务吞吐微调。** 只接受相同目标模型、并发负载下的吞吐/质量实测；019 FP8已有负证据，不原样重跑。
- **本轮暂缓：** 从头训练、换大型模型、完整世界模型重写、大规模多agent投票、并行重玩隐藏游戏或逐题oracle挑解法。它们缺少剩余时间内可比的收益证据。

候选间互补可以用逐题结果诊断，但`max(009_i, candidate_i)`只是研究者事后知道答案的上界；没有合法在线路由器就不是可提交的集成。不要再用这类上界包装预计榜分。
